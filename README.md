# Escape Room Webspill

Dette er et enkelt norsk escape room-spill laget i HTML, CSS og JavaScript.

## Beskrivelse

Spillet består av flere sider som viser ulike rom og miljøer. Spilleren navigerer mellom sidene ved hjelp av piler og interaktive områder og må finne gjenstander og bruke riktig kode for å komme videre.

## Hvordan spille

1. Åpne index.html i en nettleser.
2. Bruk pilene på skjermen for å gå til forskjellige rom.
3. Finn gjenstander og samle dem i progresjonen.
4. Bruk kodelåsen for å komme inn i verkstedet.
5. Koden for kodelåsen er 0205.
6. Trykk på Reset Progress for å starte på nytt.

## Innhold i prosjektet

- index.html - startside for escape room.
- outside.html, wall.html, toilet.html, inside_toilet.html, toolshed.html, celle_door.html, keypad.html, hole_wall.html, end.html - forskjellige rom og scener.
- style.css - styling for alle sidene.
- script.js - JavaScript for spillprogresjon, oppgavehåndtering og navigasjon.
- img/ - bilder som brukes i spillet.

## Teknologi

- HTML
- CSS
- JavaScript

## Merk

Spillet bruker sessionStorage for å bevare hva spilleren har plukket opp i løpet av én nettleserøkt.
